# Changelog

What changed in each version of this extension, newest first.

## 0.1.0

- A *Cluster Groups* branch in the navigator, with every cluster under *All clusters*.
- Create, edit and delete groups of clusters, kept across restarts.
- Connect every cluster in a group, or every cluster you have, in one click.
- *Add to cluster groups…* on every cluster's right-click menu in the navigator.
- Click a cluster in a group to open its pods, connecting it first when needed.
- Command palette commands to connect all clusters and to create a group.
